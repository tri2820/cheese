## Summary

## Currently Available

### 1. `wlr-layer-shell-unstable-v1` 
**Status bars, panels, docks, and desktop widgets**

- Create surfaces that stick to screen edges
- Reserve exclusive zones (push windows away)
- Choose layer: background, bottom, top, overlay
- Used by: waybar, yambar, eww, mako, swaylock

**Example:** `examples/statusbar/` - A waybar-like status bar

### 2. `wlr-data-control-unstable-v1`
**Advanced clipboard and selection management**

- Control clipboard contents programmatically
- Monitor clipboard changes
- Access primary selection (middle-click paste)
- Used by: clipboard managers, automation tools

**Use cases:**
- Clipboard managers (like clipman, wl-clipboard)
- Clipboard history
- Cross-device clipboard sync
- Automation scripts

## Protocol Details

### wlr-layer-shell-unstable-v1

```go
import "github.com/tri2820/cheese/protocols/wlr_layer_shell_unstable_v1"

// Get layer shell
layerShell := wlr_layer_shell_unstable_v1.NewZwlrLayerShellV1(ctx)

// Create layer surface
layerSurf, _ := layerShell.GetLayerSurface(
    surface,
    output,  // nil = any output
    uint32(wlr_layer_shell_unstable_v1.ZwlrLayerShellV1LayerTop),
    "my-bar",
)

// Configure
layerSurf.SetAnchor(uint32(
    wlr_layer_shell_unstable_v1.ZwlrLayerSurfaceV1AnchorTop |
    wlr_layer_shell_unstable_v1.ZwlrLayerSurfaceV1AnchorLeft |
    wlr_layer_shell_unstable_v1.ZwlrLayerSurfaceV1AnchorRight,
))
layerSurf.SetSize(0, 30)  // full width, 30px height
layerSurf.SetExclusiveZone(30)
```

**Layers:**
- `LayerBackground` - Desktop wallpaper
- `LayerBottom` - Below windows
- `LayerTop` - Above windows (typical for bars)
- `LayerOverlay` - Above everything

### wlr-data-control-unstable-v1

```go
import "github.com/tri2820/cheese/protocols/wlr_data_control_unstable_v1"

// Get data control manager
dcManager := wlr_data_control_unstable_v1.NewZwlrDataControlManagerV1(ctx)

// Get data control device for a seat
device, _ := dcManager.GetDataDevice(seat)

// Listen for clipboard changes
device.SetDataOfferHandler(func(ev ...) {
    // New clipboard content available
})

// Set clipboard content
source, _ := dcManager.CreateDataSource()
source.Offer("text/plain")
source.Offer("text/html")
device.SetSelection(source, serial)
```

## Adding More Protocols

If you need protocols not in your nix store:

1. **Download from wlroots:**
   ```bash
   curl -O https://gitlab.freedesktop.org/wlroots/wlr-protocols/-/raw/master/unstable/wlr-output-management-unstable-v1.xml
   ```

2. **Generate:**
   ```bash
   ./wayland-scanner \
       -i wlr-output-management-unstable-v1.xml \
       -o protocols/wlr_output_management_unstable_v1/wlr_output_management_unstable_v1.go \
       -pkg wlr_output_management_unstable_v1
   ```

3. **Use:**
   ```go
   import "github.com/tri2820/cheese/protocols/wlr_output_management_unstable_v1"
   ```

## Example: Clipboard Manager

Here's how you'd build a simple clipboard manager:

```go
package main

import (
    "github.com/tri2820/cheese/protocols/client"
    "github.com/tri2820/cheese/protocols/wlr_data_control_unstable_v1"
)

func main() {
    display, _ := client.Connect("")
    registry, _ := display.GetRegistry()
    
    var dcManager *wlr_data_control_unstable_v1.ZwlrDataControlManagerV1
    var seat *client.WlSeat
    
    registry.SetGlobalHandler(func(ev client.WlRegistryGlobalEvent) {
        switch ev.Interface {
        case "zwlr_data_control_manager_v1":
            dcManager = wlr_data_control_unstable_v1.NewZwlrDataControlManagerV1(display.Context())
            registry.Bind(ev.Name, "zwlr_data_control_manager_v1", 1, dcManager)
        case "wl_seat":
            seat = client.NewWlSeat(display.Context())
            registry.Bind(ev.Name, "wl_seat", 1, seat)
        }
    })
    
    // Roundtrip...
    
    device, _ := dcManager.GetDataDevice(seat)
    device.SetDataOfferHandler(func(ev ...) {
        // Store clipboard content in history
        fmt.Println("Clipboard changed!")
    })
    
    // Event loop...
}
```
